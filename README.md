# SchoolQuest - Gamified Campus Ecosystem

A modern, fully-functional web app that turns homework, attendance, and school participation into an interactive multiplayer RPG experience.

## 🎮 Features

✅ **User Authentication**
- Sign Up with Email & Password
- Sign In with saved credentials
- Google OAuth Integration
- Persistent login with localStorage

✅ **Student Dashboard**
- Active quests with due dates & XP rewards
- Guild memberships
- Inventory management
- XP progress tracking

✅ **Modern UI**
- Glassmorphism design (inspired by GameEd, AWorld, Forest)
- Neon gradients (Cyan, Pink, Purple)
- Smooth animations & hover effects
- Fully responsive mobile/tablet/desktop
- Dark theme with premium feel

✅ **Core Features**
- Homework Battles (Boss Raids)
- Study Guilds (Subject-based communities)
- School Store (Redeem gold for real rewards)
- Real-time leaderboards
- Achievement system

## 🚀 Quick Start

### Option 1: Run Locally (Fastest)

1. Clone the repository:
   ```bash
   git clone https://github.com/hithesh13579/schoolquest-web.git
   cd schoolquest-web
   ```

2. Open in browser:
   - Double-click `index.html` OR
   - Run a local server: `python -m http.server 8000`
   - Visit: `http://localhost:8000`

### Option 2: Enable GitHub Pages

1. Go to repository settings: **https://github.com/hithesh13579/schoolquest-web/settings/pages**
2. Under **Source**, select:
   - **Deploy from a branch**
   - **Branch: main**
   - **Folder: / (root)**
3. Click **Save**
4. Wait 1-2 minutes for GitHub to build
5. Visit: **https://hithesh13579.github.io/schoolquest-web/**

## 🎯 Testing the App

### Sign Up:
- Click **SIGN UP** button
- Enter any name, email, password
- Click **CREATE ACCOUNT**
- Dashboard loads automatically

### Sign In:
- Click **SIGN IN** button
- Use any previously created account
- Click **SIGN IN**

### Google Login:
- Click **SIGN IN WITH GOOGLE**
- Authenticate with your Google account
- Automatic dashboard access

### View Dashboard:
- After login, see:
  - Current level & XP progress bar
  - Active quests from teachers
  - Study guild memberships
  - Inventory with items & gold

### Logout:
- Click **LOGOUT** button (top-right)
- Returns to landing page
- User data cleared
